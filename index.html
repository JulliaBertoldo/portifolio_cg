Design Editorial / Alura

Página de Menu: Receita de Cheesecake

Contexto: Desenvolvimento de uma peça de design editorial no formato de página de menu, unindo tipografia refinada e fotografia de produto de forma harmônica.

Processo Criativo: O layout foi estruturado simulando a página de um menu impresso tradicional. Utilizou-se uma malha editorial rigorosa para equilibrar a área de texto com o peso visual da fotografia da sobremesa. A tipografia utilizou Playfair Display para títulos e Cormorant Garamond Light para o corpo.
Identidade Eventos / Alura

Convite: Festival de Música de Primavera

Contexto: Criação de um convite comemorativo institucional com estética leve, fluida e primaveril para um festival de música ao ar livre.

Processo Criativo: O foco central do projeto foi o equilíbrio entre o espaço em branco (respiro) e o elemento botânico. O convite foi diagramado utilizando a tipografia Cormorant Garamond em caixa alta para os títulos de cabeçalho, remetendo aos formatos de cartazes europeus clássicos.
Design Editorial Digital / Pessoal

UI Design: Interface de Alta Performance para Fórmula 1

Contexto: Concepção visual e estruturação de uma interface web voltada para o universo do automobilismo, aplicando conceitos de design tradicional (alinhamento e blocos) na arquitetura de telas digitais.

Processo Criativo: O projeto explorou um grid geométrico assimétrico de forte impacto visual, simulando o dinamismo e a velocidade das pistas. A identidade cromática utilizou cores de alto contraste e a tipografia foi cuidadosamente selecionada para garantir legibilidade técnica, mantendo o respiro visual necessário para organizar tabelas de classificação, dados estatísticos e imagens em alta definição.
